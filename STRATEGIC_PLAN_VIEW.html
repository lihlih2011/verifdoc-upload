02. Business Model & Finances

Modèle Économique (Revenue Streams)

  • Freemium : 5 scans gratuits/mois (Acquisition).
  • Pro (49€/mois) : 200 scans, Accès API, Support prioritaire.
  • Enterprise : Sur devis (Illimité, SLA, Instance dédiée).
  • API Only : 0.10€ / appel (Pour les Intégrateurs).

Objectifs Profitabilité

Point mort estimé à 15 clients Pro. Objectif Q1 2026 : 50 clients récurrents pour un MRR de 2500€.

03. Stratégie CRM & Vente

Automatisation maximale pour se concentrer sur le produit.

Outils & Workflow

  • HubSpot / Brevo : Centralisation des prospects.
  • Pipeline : Visiteur ➔ Utilisateur Free (Lead) ➔ Abonné Pro (Client).
  • Trigger : Email automatique si > 5 documents analysés ("Besoin de plus de volume ?").

04. Sécurité & Infrastructure

Cyber-Défense

  • Serveurs : OVH Public Cloud, Debian 12 durcie.
  • Accès : Clés SSH ED25519 uniquement, Port 22 restreint.
  • Données : Chiffrement AES-256 au repos. Rétention courte (RGPD).

Maintenance

  • Docker : Déploiement conteneurisé prédictible.
  • Backups : Sauvegarde S3 chiffrée quotidienne.
